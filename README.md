# Quantum Reimagined

![QR](./images/quantum-reimagined.png)

### A new visual direction for your VS Code workspace.

Quantum Reimagined is a collection of carefully designed Visual Studio Code themes, exploring different color environments and visual identities while keeping your editor comfortable and readable.

Inspired by the original [Quantum VS Code Theme](https://github.com/calebephrem/quantum-vscode) by [Caleb Ephrem](https://github.com/calebephrem), this is an independent project with its own implementation, visual direction, and theme collection.

---

## Themes

Quantum Reimagined currently includes nine theme variants:

| Theme | Theme file |
|---|---|
| Quantum Solar | `quantum-solar-v2.json` |
| Sonic | `sonic-v2.json` |
| Hydrogen | `hydrogen-v2.json` |
| Carbon | `carbon-v2.json` |
| Argon | `argon-v2.json` |
| Geco | `geco-v2.json` |
| Terminator | `terminator-v2.json` |
| Mars | `mars-v2.json` |
| Elliptical | `elliptical-v2.json` |

Each variant offers a different visual atmosphere. Explore them and choose the environment that works best for your workflow.

## Installation

### From Visual Studio Code Marketplace

1. Open Visual Studio Code.
2. Open the Extensions view (`Ctrl + Shift + X`).
3. Search for **Quantum Reimagined**.
4. Select the extension and click **Install**.

### From VSIX

If you have downloaded the `.vsix` package:

1. Open Visual Studio Code.
2. Open the Extensions view.
3. Select the three-dot menu.
4. Choose **Install from VSIX...**.
5. Select the downloaded package.

---

## Selecting a Theme

1. Open the Command Palette (`Ctrl + Shift + P`).
2. Search for `Preferences: Color Theme`.
3. Select **Quantum Reimagined**.
4. Choose your preferred variant.

You can switch between variants whenever you want.
